# Arena Combat Lab

A standalone Godot 4 combat laboratory for prototyping the tactical combat layer intended for First Fire.

## Alpha 0.1 vertical slice

One handcrafted convenience-store / gas-station map tests:

- Shared action-time timeline (fast and slow actions let enemies act at different rates)
- Directional facing and Project-Zomboid-style vision cone / fog of war
- Walking, crouch movement, sprint momentum, turn and reverse penalties
- Map-propagated noise; enemies investigate sounds that physically reach them
- Uncertain enemy intent reads derived from First Fire Combat + Survival skills and condition
- Stealth, rear vulnerability, and stealth kills
- Discrete melee and firearm resolution (no reaction / interrupt minigame)
- Doors, breakable glass, shelves, walls, and dense pathing
- Explosive barrel with blast damage, knockback, destruction, and huge noise
- Activatable noise trap / alarm for distraction
- Basic crowd pressure and fear
- Random First Fire survivor stats, equipment, and starting statuses
- Random objective-cache location
- Objective-first victory: get the supply cache and escape; killing everything is unnecessary

All actors already exist on the map. Noise never spawns enemies.

## Controls

- **WASD / Arrow keys**: move one tile
- **Shift + move**: sprint (cheaper when maintaining direction, costly to turn/reverse, loud)
- **C**: toggle crouch / sneak movement
- **Q / E**: rotate 90 degrees
- **Space**: melee the tile you are facing
- **G**: fire at the nearest visible zombie in your facing cone (if carrying a firearm)
- **F**: interact with the tile you are facing (doors, glass, alarm)
- **Left click**: attack a visible zombie; shoot a visible explosive barrel if carrying a firearm
- **R**: restart with a new random survivor/loadout/objective
- **F1**: toggle debug AI information

## Design rule

> The map is not an arena containing the combat system. The map is part of the combat system.

Alpha art is intentionally generated by code so the simulation can be iterated without asset dependencies.
